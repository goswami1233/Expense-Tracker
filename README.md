# Expense-Tracker
A simple expense tracker using HTML, CSS, and JavaScript

## 🚀 Features

- Add and delete transactions
- Calculate total balance, income, and expenses
- Stores data in browser using **localStorage**
- Fully responsive UI

## 📁 Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)
- Git & GitHub
  
  ## 🚀 Live Project

👉 [Click here to view the live site](https://goswami1233.github.io/Expense-Tracker/)

## 📌 How to Use

1. Open the app using the live demo link.
2. Enter a name and amount for each income/expense.
3. Press "Add Transaction" to add it to the list.
4. Your data will be saved automatically.
